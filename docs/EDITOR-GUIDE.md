# Website editor guide

For ISP staff who update the website. No technical knowledge is needed.

Sign in at **`/admin`** on the website (for example `https://www.isp.edu.my/admin`). The dashboard shows shortcuts to the most common tasks.

---

## The golden rules

1. **Nothing is public until you press Publish.** Your changes save automatically as a draft while you type.
2. **Preview before publishing.** Use the eye icon (Live Preview) to see the page exactly as visitors will, on phone, tablet or desktop.
3. **Only publish approved facts and photographs.** Fees, results, staff names, safeguarding information and photos of students need sign-off from the responsible owner (see *Who approves what*).
4. **Never add personal information about students** (full names, dates of birth, medical details) to the website.

---

## Your role

| Role | Can do |
| --- | --- |
| **Contributor** | Create and edit drafts of pages, news, media. Cannot publish, unpublish or delete. Ask an editor to publish. |
| **Editor** | Everything a contributor can, plus publish, unpublish and delete content, and edit the menus and footer. |
| **Admissions** | Read and manage enquiries; edit events, FAQs and admissions information (fees link, waiver, application link). |
| **Administrator** | Everything, including staff accounts and school details (addresses, phone numbers, social links). |

Administrators create accounts under **Administration → Staff users**. There is no public sign-up. After 5 wrong passwords an account is locked for 15 minutes.

## Editing a page

1. Go to **Website → Pages** and open the page.
2. The page is made of **Sections**. Click a section to open it; change the text, images or links.
3. **Reorder** sections by dragging the handle (⋮⋮) on the left.
4. **Add** a section with **Add Section** at the bottom and choose a type (see the list below).
5. **Remove or duplicate** a section with the **⋯** menu on its row.
6. Open **Live Preview** (eye icon) to check, then **Publish changes**.

The **sidebar** controls the page’s web address:

- **Slug** — the last part of the address (e.g. `primary`).
- **Parent** — places the page under another (e.g. *Learning*), giving `/learning/primary`. Moving a page updates its child pages automatically.
- **Content owner** and **Last reviewed** — record who approves the page and when it was checked.

The **Search & sharing** tab sets the title and description shown in Google and when the page is shared. If left empty, the page title and introduction are used.

### Section types

| Section | Use it for |

## Common tasks

### Post news
**Website → News & stories → Create new.** Add a title, category, date, a one-sentence excerpt, one approved photograph and the story. Publish. It appears in “Latest stories” sections and at `/community/stories`.

### Add an open day or event
**Admissions → Events → Create new.** Set start and end times (Kuala Lumpur time), campus, audience, a short summary and the booking link. Check the booking link is for this year’s event. Events stop showing on the website automatically once they end.

### Show an announcement banner
**Settings → School details → Announcement.** Tick *Enabled*, write one line, add a link and an expiry time. The banner hides itself after it expires.

### Update fees or the application link
**Admissions → Admissions information.** Change the academic year, the official fee schedule link, the waiver text or the application link. Only add amounts to the optional fee table once Finance has approved them for that year. Every page showing fees or application details updates together.

### Answer an enquiry
**Admissions → Enquiries.** Open the enquiry, reply to the parent by email, then set the status to *In progress*, *Responded* or *Closed* and add internal notes. Enquiry details are personal data: do not copy them elsewhere unnecessarily.

### Change the menu or footer
**Settings → Main menu** and **Settings → Footer.** Drag groups and links to reorder. Links can point to a page (they keep working if the page moves) or to any web address.

### Replace a photograph
**Website → Media library → Create new**, upload the image, write the alternative text (describe what is happening, never name children) and set **Approval** to *Approved for publication* once the release is confirmed. Then pick the new image in the section. Set the focal point so the important part stays visible when the image is cropped.

### Undo a mistake
Open the document and choose **Versions** at the top to see and restore earlier versions.

## Writing for the website

- Lead with what a parent needs to know; keep paragraphs short.
- Headings should describe the content (“How to apply”, not “Your journey begins”).
- Link text should make sense on its own (“View the 2026/27 fee schedule”, not “click here”).
- Every image needs alternative text unless it is purely decorative (then write `decorative`).
- Dates: “Saturday 14 November 2026”; times: “9:00am – 11:00am”.
